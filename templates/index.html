Database and Page View Counter

This application uses a MariaDB database. The page view count is stored in the laskuri table of the viikko2 database. The Python Flask application updates the counter every time the page is loaded.

Server Restart Test

I tested the application by restarting the Ubuntu virtual machine. Nginx, Flask and MariaDB started automatically after the reboot. The page view count was preserved in the database and continued increasing after the restart.
